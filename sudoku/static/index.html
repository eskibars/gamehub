How to play

Fill the grid so every row, column, and 3×3 box holds the digits 1–9 exactly once. Tap a cell, then a number (or type 1–9). Press N for pencil-mark notes, H for a hint (three per puzzle, each costs 5 chips of reward), P to pause. Harder levels pay more chips.
