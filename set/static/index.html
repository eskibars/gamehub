Set

A set is 3 cards where each attribute — number, color, shape, shading — is either all the same or all different on every card. Tap three cards that form one before the deck runs dry.

Stuck? Hint flashes one card of a real set. The table auto-refills when no sets remain.

Play with friends

Everyone shares one table. Spot a set? Smash the big SET! button — you get five seconds to point out your three cards. Miss, and you sit the next shout out.
